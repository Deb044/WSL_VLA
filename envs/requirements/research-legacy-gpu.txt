# Locked `legacy-gpu` research environment (Python 3.10, JAX 0.4.20, CUDA 11 wheels).
#
# This file is the exact `pip freeze` of the environment in which the corrected
# pipeline was verified end to end on an RTX 4050 Laptop GPU (sm_89): unit and
# integration tests, the integrity run profile, and real LIBERO rollouts. It is
# a complete transitive lock, so it must be installed WITHOUT dependency
# resolution:
#
#   envs/scripts/setup_research.sh --profile legacy-gpu <venv-directory>
#
# which runs `pip install --no-deps -r` on this file, then installs this
# repository (`pip install --no-deps -e .`) and the pinned LIBERO checkout
# (editable; its top-level package has no __init__.py). Resolving these pins
# instead would fail: TensorFlow 2.15 declares ml-dtypes~=0.2 while the verified
# environment runs ml_dtypes 0.5.0.
#
# JAX follows the installation path that was supported for the 0.4.20 release
# and that Octo documents: CUDA 11 pip wheels from the JAX release index. Only
# the NVIDIA driver must be present on the host. The environment was built
# incrementally; a from-scratch reinstall from this file has not been executed
# (see docs/methodology/METHODOLOGY1_RUNBOOK.md, "Environments").
#
# torch is required by LIBERO (it reads the fixed initial states with
# torch.load). The cu121 build and the PyTorch-side packages (peft,
# sentence-transformers, ...) are present because the verified environment also
# hosts the legacy PyTorch smoke pipeline; the research pipeline never imports
# them. mujoco is 2.3.7, the version robosuite 1.4.0 and LIBERO require.
#
